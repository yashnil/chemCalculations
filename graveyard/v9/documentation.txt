VERSION 9 CHANGES
-----------------
This version implements TWO focused modifications to v8:

1. **70-15-15 Train/Val/Test Split** (previously 60-15-25)
   - Training: 70% of data
   - Validation: 15% of data
   - Test: 15% of data
   - Provides more training data while maintaining sufficient validation/test sets

2. **Temperature Normalization by Global Maximum**
   - Old: Temperature [K] scaled via StandardScaler
   - New: Temperature normalized by global maximum → T_norm = T / T_max
   - Result: All temperature values in range [0, 1]
   - T_max saved in artefacts/normalization_params.pkl for inference

**Note**: Element encoding remains IDENTICAL to v8 (log₁₀(fraction) + 9)
         to avoid performance degradation from log-ratio transformations.

INPUT FEATURES (v9)
-------------------
Total: 7 features (same as v8)

1. temperature_norm     — T / T_max, range [0, 1]  ← CHANGED from v8
2. log_pressure         — log₁₀(P [bar])
3. log_H                — log₁₀(comp_H) + 9        ← Same as v8
4. log_O                — log₁₀(comp_O) + 9        ← Same as v8
5. log_C                — log₁₀(comp_C) + 9        ← Same as v8
6. log_N                — log₁₀(comp_N) + 9        ← Same as v8
7. log_S                — log₁₀(comp_S) + 9        ← Same as v8

OUTPUT REPRESENTATION (unchanged from v8)
-----------------------------------------
116 gas-phase species normalized mole fractions (Σ = 1.0)

MODEL ARCHITECTURE
------------------
- Input layer: 7 neurons (same as v8)
- Hidden layers: Same as v8 (tuned via Optuna)
- Output head: Softplus head with normalization
- Loss function: Composite loss (λ·balanced_KL + (1-λ)·MAE_log)

INFERENCE WORKFLOW (v9)
-----------------------
To use the trained model on new data:

```python
import joblib, numpy as np
from tensorflow import keras

# Load artefacts
model = keras.load_model("artefacts/final_model.keras")
scaler = joblib.load("artefacts/input_scaler.pkl")
norm_params = joblib.load("artefacts/normalization_params.pkl")
T_max = norm_params["T_max"]

# Prepare input (T [K], P [bar], comp_H, comp_O, comp_C, comp_N, comp_S)
T, P = 1500.0, 0.1
comp = {"H": 0.85, "O": 0.10, "C": 0.03, "N": 0.015, "S": 0.005}

# Transform to v9 features
features = np.array([[
    T / T_max,                              # temperature_norm
    np.log10(P),                            # log_pressure
    np.log10(comp["H"]) + 9.0,             # log_H
    np.log10(comp["O"]) + 9.0,             # log_O
    np.log10(comp["C"]) + 9.0,             # log_C
    np.log10(comp["N"]) + 9.0,             # log_N
    np.log10(comp["S"]) + 9.0              # log_S
]])

# Scale and predict
features_scaled = scaler.transform(features)
abundances = model.predict(features_scaled)
```

EXPECTED IMPROVEMENTS
---------------------
1. **Better generalization**: More training data (70% vs 60%)
2. **Bounded temperature**: [0,1] normalization may improve gradient flow
3. **Smaller test variance**: Same size test set, just more training data

WHY NOT LOG-RATIOS?
-------------------
Initial v9 attempted to use H-relative ratios (log₁₀(O/H) etc.) to reduce
from 7 to 6 inputs. This resulted in POOR performance:

- v8: MAE_log = 0.047, R²_log = 0.954
- v9 with ratios: MAE_log = 0.142, R²_log = 0.830  (3× WORSE!)

Root cause: Log-ratios create high-variance features (std ≈ 3.66 vs v8's 2.5)
and remove information about absolute hydrogen abundance.

**Decision**: Keep v8's element encoding, only change split ratio and T normalization.

COMPATIBILITY WITH V8
---------------------
- Uses same data source (all_gas.csv)
- Uses same species filtering (drop T-bin 0)
- Uses same loss functions and model head
- Uses same element encoding (log + 9)
- Different: split ratio (70-15-15 vs 60-15-25)
- Different: temperature normalization (T/T_max vs StandardScaler)
- NOT backward compatible: v9 models cannot use v8 scalers
