# Plots and Results

This directory contains visualization outputs and result tables from model training and hyperparameter studies.

## Key Visualizations

- **`latent_dim_study.png`**: Test/validation loss vs. latent dimension (Test #1)
- **`layer_width_study.png`**: Test loss vs. layer width and depth (Test #2)
- **`dataset_size_study_optimal.png`**: Performance metrics vs. dataset size (Test #3)
- **`resolution_study.png`**: Overall performance across dataset sizes
- **`loss_curves.png`**: Training dynamics (loss vs. epochs)
- **`model_comparison.png`**: Comparison across different model configurations
- **`performance_vs_size.png`**: Performance metrics as function of dataset size

## Results Tables

- **`comparison_metrics.csv`**: Comprehensive performance metrics for all model configurations
- **`hyperparameters_table.csv`**: Complete hyperparameter table for all models tested
- **`latent_dim_results.csv`**: Results from latent dimension study
- **`layer_width_results.csv`**: Results from layer width study
- **`dataset_size_results_optimal.csv`**: Results from dataset size study with optimal hyperparameters
